# CF4 Do Not Confuse Sheet

| A | B | Exact Difference | Fast Exam Cue |
|---|---|---|---|
| Revenue | Cash Receipt | Earning/recognition vs payment timing | “earned?” |
| Expense | Cash Payment | Incurrence/consumption vs payment timing | “incurred?” |
| Net Income | OCF | Accrual performance vs operating cash | profit ≠ cash |
| OCF | FCF | Operating cash vs cash after reinvestment | CapEx/NWC matter |
| Retained Earnings | Cash | Equity account vs asset | RE is not a reserve |
| Debt | Liabilities | Debt may be narrower | read definition |
| Debt | Equity | Contractual vs residual claim | fixed obligation? |
| Secured | Senior | Collateral vs priority | collateral ≠ ranking |
| Unsecured | Subordinated | No collateral vs lower priority | separate axes |
| Common | Preferred | Residual common claim vs priority equity claim | preferred is not debt |
| Coupon | Yield | Contractual coupon vs market-required return | price changes yield |
| Book Value | Market Value | Accounting amount vs observed price | measurement basis |
| Market Value | Intrinsic Value | Observed price vs model-estimated value | market ≠ model |
| Required Return | Expected Return | demanded vs anticipated | both ex ante |
| Expected Return | Realized Return | anticipated vs actual | ex ante vs ex post |
| Arithmetic Average | CAGR | mean one-period return vs compound wealth growth | volatility drag |
| Nominal Return | Real Return | money return vs purchasing-power return | inflation adjustment |
| Volatility | Beta | total dispersion vs market sensitivity | total vs systematic |
| Cost of Capital | WACC | component/project concept vs weighted firm benchmark | aggregation |
| Company WACC | Project Rate | firm-average risk vs project-specific risk | risk match |
| NPV | IRR | value amount vs break-even rate | value vs rate |
| IRR | ARR | discounted cash-flow rate vs accounting return | TVM vs accounting |
| Payback | NPV | recovery speed vs value creation | liquidity vs value |
| Brigham PI | Berk PI | PV inflows/initial investment vs NPV/resource consumed | read definition |
| Payoff | Profit | terminal contract value vs payoff net of premium/cost | premium |
| Forward | Option | obligation vs right | no zero-floor in forward |
| Hedging | Speculation | risk reduction vs exposure creation | existing exposure? |
| Agency Problem | Agency Cost | conflict vs economic consequence/mitigation cost | cause vs consequence |
| Financial Asset | Real Resource | claim vs productive resource | financing vs operations |
| Growth | Value Creation | expansion vs return above opportunity cost | compare to WACC |
| Good News | Positive Return | headline label vs surprise relative to expectations | already priced? |

## Critical Convention Alerts

### Debt

```text
Debt
→ problem-defined
→ interest-bearing debt OR total liabilities
```

### PI

```text
Brigham PI ≠ Berk scarce-resource PI
```

### ROA / Turnover

```text
average vs ending balance
→ follow problem/source
```
