# CF4 — Stage 7: Knowledge Status Assignment

> [!ABSTRACT] Tujuan
> Stage 7 mengubah hierarchy Stage 6 menjadi **operational study policy**.
>
> Setiap Level-1/2/3 item diberi satu primary status:
>
> - **MEMORIZE**
> - **UNDERSTAND / RECONSTRUCT**
> - **REFERENCE ONLY**
> - **AVOID AS DEFAULT**
>
> Status ini menjawab **bagaimana item dipelajari**, bukan apakah item tersebut benar/salah atau masuk/tidak masuk silabus.

## 1. Important Boundary

> [!IMPORTANT]
> **Formula-specific status belum final di Stage 7.**
>
> Misalnya WACC, CAPM, NPV, IRR, ratio formulas, dan derivative formulas di sini diberi **knowledge/concept status**. Keputusan final apakah suatu *formula form* harus MEMORIZE / RECONSTRUCT / REFERENCE ONLY / AVOID AS DEFAULT akan dilakukan lagi pada **Stage 9 — Canonical Formula Layer** setelah formula conventions direkonsiliasi.
>
> Dengan kata lain:
>
> **Stage 7 = knowledge retrieval policy**  
> **Stage 9 = formula retrieval policy**

## 2. Status Definitions

| Status | Meaning | Study Behavior |
|---|---|---|
| **MEMORIZE** | Harus dapat dikenali/di-recall cepat karena definisi, distinction, classification, atau rule-nya central dan reconstruction cost/error risk tinggi. | Active recall sampai retrieval hampir otomatis. |
| **UNDERSTAND / RECONSTRUCT** | Lebih aman dibangun dari Level-0/Level-1 reasoning daripada menghafal wording atau banyak special cases. | Latih derivation/reasoning path. |
| **REFERENCE ONLY** | Valid dan potentially examinable, tetapi detail/extension/source-context tidak layak mengambil primary working memory. | Simpan dalam master reference; review on demand. |
| **AVOID AS DEFAULT** | Valid hanya sebagai shortcut/context/check tetapi berisiko menyesatkan jika dijadikan first-line reasoning. | Jangan mulai dari item ini; kembali ke canonical protocol. |

## 3. Level 0 Policy — Universal Reasoning Protocols

Level 0 **tidak diberi salah satu dari empat status biasa**. Seluruh Level-0 rules dianggap:

> **CORE PROTOCOL — internalize and execute automatically**

| ID | Protocol | Operational Requirement |
|---|---|---|
| L0-A1 | Accounting Substance First | Internalize the sequence: Economic event → recognition → measurement → presentation/disclosure → statement effect → interpretation. |
| L0-A2 | Accrual Timing Rule | Internalize the sequence: Earn/incur determines accounting recognition; cash timing may differ. |
| L0-A3 | Statement Linkage Rule | Internalize the sequence: Income Statement → Net Income → Retained Earnings/Equity → Statement of Financial Position. |
| L0-A4 | Accounting Equation Check | Internalize the sequence: Assets = Liabilities + Equity after every transaction set. |
| L0-A5 | Group-as-One-Entity Rule | Internalize the sequence: If control exists, consolidated accounts treat parent + subsidiary as one economic reporting entity; internal effects are eliminated. |
| L0-R1 | Ratio Interpretation Rule | Internalize the sequence: Statement data → formula → calculation → comparison → direction → interpretation → limitation. |
| L0-S1 | Security Rights Rule | Internalize the sequence: Instrument → cash-flow rights → priority → maturity → optionality → risk → return → issuer/investor consequence. |
| L0-F1 | Financing Choice Rule | Internalize the sequence: Funding need → maturity → source → cost → commitment/collateral → flexibility → funding risk. |
| L0-C1 | Corporate Finance Value Rule | Internalize the sequence: Decision → incremental cash flow → risk → required return/cost of capital → present value → value creation. |
| L0-C2 | Project Relevance Rule | Internalize the sequence: Include incremental future cash flows and opportunity costs; exclude sunk costs. |
| L0-C3 | Risk-Rate Matching Rule | Internalize the sequence: Discount rate must match the risk of the cash flows; company WACC is not universally valid for every project. |
| L0-M1 | Market Valuation Rule | Internalize the sequence: Expected cash flow ↑ raises value; required return ↑ lowers value, ceteris paribus. |
| L0-M2 | Economic-Channel Rule | Internalize the sequence: Economic variable → expected cash flow and/or required return/risk premium → price → total return. |
| L0-M3 | Expectation-Surprise Rule | Internalize the sequence: Market reaction depends on new information relative to prior expectations, not merely whether the news sounds good/bad. |
| L0-K1 | Perspective Rule | Internalize the sequence: Always identify whose perspective applies: company/issuer, investor/shareholder, creditor/lender, analyst, or management. |
| L0-K2 | Terminology Boundary Rule | Internalize the sequence: Do not merge terms merely because values can coincide; map aliases only when concepts are genuinely identical. |
| L0-K3 | Source-Convention Rule | Internalize the sequence: When official sources use different formula conventions, preserve the convention explicitly rather than silently merging. |

## 6. MEMORIZE Layer — What “Memorize” Means in CF4

For CF4, MEMORIZE does **not** mean memorizing textbook paragraphs word-for-word.

The target is compact retrieval of:

```text
Term
→ definition / critical distinction
→ perspective
→ one exam implication
```

Examples:

```text
Revenue
→ earned accounting income
→ not necessarily cash received
```

```text
Secured debt
→ collateral dimension
→ not the same as seniority
```

```text
Required return
→ ex-ante compensation demanded for risk
→ not realized return
```

```text
NPV
→ present-value value creation
→ positive NPV creates value
```

### Mandatory High-Speed Distinctions

These should become near-automatic:

- Revenue ≠ Cash Receipt
- Expense ≠ Cash Payment
- Retained Earnings ≠ Cash
- Debt ≠ Liabilities
- Debt ≠ Equity
- Secured ≠ Senior
- Coupon Rate ≠ Yield
- Book Value ≠ Market Value ≠ Intrinsic Value
- Required ≠ Expected ≠ Realized Return
- Volatility ≠ Systematic Risk ≠ Beta
- Nominal ≠ Real Return
- Cost of Capital ≠ WACC
- Company WACC ≠ Project Discount Rate
- NPV ≠ IRR
- IRR ≠ Accounting Rate of Return
- Forward ≠ Futures
- Payoff ≠ Profit
- Hedging ≠ Speculation
- Agency Problem ≠ Agency Cost
- Financial Asset ≠ Real Resource

### 9.2 Historical Return Sample Values

Do not memorize 1926–2011 sample returns/volatilities as if they were universal market parameters.

## 11. Cognitive-Load Rule

When two correct items compete for memory, prefer:

1. the more general Level-0/Level-1 rule;
2. the definition with lower ambiguity;
3. the route that can reconstruct more downstream concepts;
4. the convention explicitly required by the source/question.

Do not memorize multiple equivalent explanations merely because multiple textbooks use them.

## 12. Escalation Rule

A REFERENCE ONLY item may be promoted later if past-exam validation shows:

- recurring direct questions;
- repeated need for exact retrieval;
- reconstruction too slow for exam conditions.

An UNDERSTAND / RECONSTRUCT item may be promoted to MEMORIZE if:

- the reasoning path is repeatedly too long;
- small reconstruction errors materially affect answers;
- official questions repeatedly require direct recall.

A MEMORIZE item may be demoted if:

- it proves easily reconstructable;
- it is not actually within validated syllabus depth;
- it merely duplicates another canonical primitive.
