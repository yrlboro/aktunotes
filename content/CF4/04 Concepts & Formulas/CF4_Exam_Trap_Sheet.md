# CF4 Exam Trap Sheet

| Trap | Correct Rule | Prevention Cue |
|---|---|---|
| Cash receipt = revenue | Revenue follows earning | earned? |
| Cash payment = expense | Expense follows incurrence | incurred? |
| Retained earnings = cash | RE is equity | asset or equity? |
| Borrowing = revenue | Borrowing creates liability | financing |
| Principal repayment = expense | Principal settles liability | separate interest |
| Dividend = expense | Dividend is owner distribution | equity payout |
| AR collection = new revenue | Revenue already recognized | asset swap |
| Customer advance = revenue | Liability until earned | performance first |
| Depreciation = cash outflow | Noncash expense; tax effect possible | add-back logic |
| Higher current ratio = always better | Composition/efficiency matter | driver? |
| Higher ROE = better operations | Leverage can raise ROE | DuPont |
| Sales / inventory | Use COGS / average inventory | turnover family |
| Debt = total liabilities | Read problem definition | critical |
| Secured = senior | Collateral ≠ priority | separate axes |
| Preferred = debt | Separate capital component | claim type |
| Cheapest short-term financing is best | Funding/refinancing risk matters | maturity match |
| Trade discount % = annual cost | Annualize implicit financing cost | extra-credit days |
| Secondary sale = company financing | Company receives no new cash | who gets proceeds? |
| Underpricing = underwriting spread | Different issuance costs | direct vs indirect |
| Dilution = automatic wealth loss | % ownership ≠ value loss necessarily | issue price/value |
| Option payoff = profit | Include premium | payoff then premium |
| Forward payoff has zero floor | Forward is obligation | no max() |
| Hedge loses = hedge failed | Evaluate combined position | underlying + derivative |
| Net income = project cash flow | Use incremental cash flow | with vs without |
| Sunk cost included | Exclude sunk costs | already spent |
| Opportunity cost omitted | Include forgone value | alternative use |
| CapEx = expense | Accounting capitalization vs CF outflow | accounting vs CF |
| ΔNWC ignored | Increase uses cash | NWC ↑ → FCF ↓ |
| Tax-adjust equity cost | Tax shield applies to debt | debt only |
| Book weights automatic in WACC | Use target/market weights | source/problem |
| Company WACC for every project | Match project risk | risk match |
| Highest IRR always best | NPV is value benchmark | mutually exclusive? |
| One IRR always exists | Nonnormal CF may create multiple/no IRRs | sign pattern |
| Shortest payback = highest value | Payback is recovery metric | NPV |
| ARR = IRR | Accounting vs DCF return | TVM |
| PI convention inferred from author/topic | Read exact definition | critical |
| Agency problem = agency cost | Conflict vs consequence | cause/effect |
| Governance always increases value | Governance has costs | trade-off |
| Growth = value creation | Compare return with WACC | spread |
| Historical average = expected return | Historical estimate only | ex post data |
| CAGR = arithmetic average | Compound vs mean | wealth path |
| Volatility = beta | Total vs systematic risk | CAPM |
| CAPM uses market return in beta term | Use market risk premium | subtract rf |
| Risky asset must earn > rf | Negative beta can imply below-rf CAPM return | beta sign |
| Real = nominal − inflation exactly | Subtraction is approximation | exact multiplicative |
| Coupon = yield | Contractual vs market rate | bond pricing |
| Higher rates good/bad for everyone | Stakeholder matters | issuer/new/existing holder |
| Good news = positive return | Expectations and discount rate matter | surprise |
| Inflation ↑ = all assets ↓ | Multiple channels | cash flow + discount rate |
| Recession = all rates ↑ | Risk-free rate and spreads can diverge | separate components |
| Positive alpha = arbitrage | Model-relative | omitted risk/model error |
