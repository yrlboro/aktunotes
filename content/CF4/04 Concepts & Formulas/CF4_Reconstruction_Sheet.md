# CF4 Reconstruction Sheet

## Accounting

```text
earned/incurred?
vs
paid/received?
```

This rebuilds credit sales, AR collection, accruals, prepayments, advances and payment timing.

## Ratios

```text
flow
÷
stock
```

Then ask:

```text
which flow?
which stock?
average or ending?
```

## Debt / Equity

```text
contractual claim?
or
residual ownership?
```

## Secured / Senior

```text
collateral?
priority?
```

## Option

```text
Call = right to buy
Put = right to sell
```

Then compare terminal price with strike.

## Forward

```text
long pays K for something worth S_T
→ S_T - K
```

## WACC

```text
weighted required returns
+
tax-adjust debt only
```

```text

-
```

## NPV

```text
PV every incremental cash flow
and sum
```

## IRR

```text
the rate that makes NPV = 0
```

## MIRR

```text
move costs to t0
move inflows to terminal date
solve connecting compound rate
```

## Incremental IRR

```text
mutually exclusive projects
→ subtract cash-flow streams
→ IRR of difference
```
